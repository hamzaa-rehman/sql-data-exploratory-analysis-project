# SQL Data Exploratory Analysis Project

A practical SQL project focused on exploring and analyzing relational data to uncover meaningful trends, patterns, customer behavior, product performance, and actionable business insights.

This repository contains SQL scripts covering different stages of data analysis, including:

* Database exploration
* Measures and metrics
* Change over time analysis
* Cumulative analysis
* Performance analysis
* Part-to-whole analysis
* Data segmentation
* Advanced SQL techniques
* Final analytical reporting

The project demonstrates how SQL can be used to transform raw data into meaningful insights through structured querying, aggregation, window functions, CTEs, and analytical techniques.

---

## 🎯 Project Objectives

* Explore and understand the underlying data.
* Analyze sales, customers, and products using SQL.
* Identify trends and patterns over time.
* Measure product and customer performance.
* Analyze contribution to overall sales.
* Segment products and customers based on business criteria.
* Develop reusable SQL queries for analytical reporting.

## 📊 Analytical Areas

### Change Over Time

Analyze sales and other metrics across different time periods to identify trends, growth, and changes over time.

### Cumulative Analysis

Calculate running totals and moving averages to understand accumulated performance and smooth short-term fluctuations.

### Performance Analysis

Evaluate product performance by comparing current results with previous periods and average performance.

### Part-to-Whole Analysis

Determine how individual products, categories, or other segments contribute to overall sales.

### Data Segmentation

Group products and customers into meaningful segments based on defined business rules and metrics.

## 🧠 Analytical Approach

The project follows a structured approach to solving SQL analysis problems:

```text
Business Question
        ↓
Define Granularity
        ↓
Identify Dimensions & Metrics
        ↓
Build Base Dataset
        ↓
Aggregate Data
        ↓
Apply Analytical Calculations
        ↓
Generate Insights
        ↓
Final Report
```

A key focus of the project is understanding **data granularity** and ensuring that each metric is calculated at the appropriate level of detail.
